# Basic Chatbot Using Python

## Description
Basic Chatbot is a simple rule-based chatbot developed using Python. It interacts with users and provides predefined responses based on their messages.

## Features
- Responds to greetings.
- Answers simple questions.
- Provides goodbye messages.
- Continuous conversation until the user exits.

## Technologies Used
- Python

## Concepts Used
- Functions
- If-Else Statements
- Loops
- User Input and Output

## How to Run
1. Install Python.
2. Open `basic_chatbot.py`.
3. Run the program.
4. Type a message and interact with the chatbot.
